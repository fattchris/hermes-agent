## ⚠️ Breaking Changes

### Device Selection Change (CRITICAL)

vLLM **no longer sets `CUDA_VISIBLE_DEVICES` internally**. A new `device_ids` argument replaces it.

```bash
# OLD (v0.23.x and earlier) — vLLM set CUDA_VISIBLE_DEVICES internally
CUDA_VISIBLE_DEVICES=0,1 vllm serve MODEL --tensor-parallel-size 2

# NEW (v0.24.0) — use device_ids argument for explicit GPU selection
vllm serve MODEL --tensor-parallel-size 2 --device-ids 0,1
```

**Migration:** `CUDA_VISIBLE_DEVICES` still works as a container-level env var (the OS/CUDA applies it before vLLM starts). But vLLM no longer internally sets it based on `--tensor-parallel-size`. Use `--device-ids` for explicit GPU selection within vLLM.

**ROCm:** Deprecation window for `CUDA_VISIBLE_DEVICES` on ROCm has begun.

### Removed Models
ERNIE, Xverse, Dots1, Bamba, Mono-InternVL, InternLM registry alias

### Deprecated
First-generation Qwen and QwenVL models, Transformers v4 support, `CUDA_VISIBLE_DEVICES` on ROCm
